The standard is now repo-contract's `strict` tier with IPC's hardening passed as options. Check ids and their order are unchanged, except that `QuickStart` joins the set after `PackedConsumer`. It needs repo-contract 0.16.0, which ships `repo-contract/tiers`; the package now depends on `repo-contract@~0.16.0`.

- **Same limits, now stated as tier options.** `checks/strict.ts` holds them: coverage 80% on all four metrics, CRAP 30, complexity 20, duplication 0.75% of `src/`, mutation 100%. `contract.ts` carries the tier metadata, so `repo-contract explain` reads IPC's real settings.
- **repo-contract runs Coverage, Crap, Mutation, Duplication, DocsMarkdown, BundledDependencies, Packaging and the npm-script checks.** `IPC_MUTATION_SHARD`, `IPC_MUTATION_REPORT`, `IPC_MUTATION_MEMO` and `CI` map onto the Mutation preset's options. `--scope affected` narrows Mutation's `mutate` list, still warns on Coverage and still judges only the affected sources in Crap.
- **Where the options differ from the tier.** Every numeric limit is at least as strict, and `Build` fails a package with no build script. Three options narrow what is judged: `Duplication` scans `src/`, `TypeResolution` ignores the `node10` resolver, and `Crap` ignores the managed `_ipc/` copies.
- **Behaviour changes.** On a `private: true` package, Packaging, TypeResolution and BundledDependencies pass as not applicable. A package whose only Stryker config is `stryker.conf.cjs` now gets its own config, not the bundled one. Under `--scope affected`, `Crap` fails instead of rewriting `reports/crap.json` through a symbolic link. A record whose `expires` is not a real date fails to load, and a load error now names every problem in the record. Rationale wording follows repo-contract's presets.
- **Kept as IPC's own.** `Tests`, `SecurityDeps` (an `info` advisory still needs a record), `DocsLinks` (unreachable external links stay environment degradations), `DistNoUrls`, `SecuritySecrets`, `DeadCode` and `Commits`.
- **Breaking: removed exports.** `checks/coverage`, `checks/crap`, `checks/mutation`, `checks/duplication`, `checks/docs-markdown`, `checks/bundled-dependencies`, `checks/npm-script` and `checks/exception-record` are gone; import the presets and the version 2 record from `repo-contract/presets` and `repo-contract/helpers`. `checks/arethetypeswrong` now exports `typeResolutionCheck(check)`. `scripts/run-mutation.mjs`, `scripts/run-generated.mjs`, `scripts/stryker-vitest5-compat.mjs` and eight `scripts/mutation/*` helpers (`adopt`, `confirm-timeouts`, `memo`, `merge`, `mutant-free`, `narrow`, `report-shape`, `shard`) are gone; `repo-contract mutation run` and `repo-contract npm-script` replace them.
