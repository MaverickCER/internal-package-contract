The shared `no-node-fs` rule also reports `node:fs` reached through a re-export (`export ... from`, `export * from`) or TypeScript's `import x = require()`, and matches an `allow` pattern written relative to the working directory (`src/cli/**`) against the absolute path ESLint gives it, on Windows too; the matching is the shared `glob` copy's new `matchesAllowList`, so a package's own lint rules can use the same. A benchmark report shows only the first line of a failure's message, so a stack trace and the paths of the machine that ran it stay out of the published page. WRITING-BENCHMARKS.md records the two exceptions suites already use (a per-function `tiers` with its `tiersReason`, and benchmarking internal source), and the scaffolded and environment-rotation workflows pin the same v7 checkout, setup-node and upload-artifact actions as the rest. This package's own release works again under Changesets 3, which stopped versioning a private package unless `privatePackages.version` is set: the Version Packages pull request for this release could not be opened without it.
