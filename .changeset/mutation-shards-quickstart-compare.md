Shard mutation through repo-contract, make `QuickStart` standard, and compare consumer verdicts check by check.

- **Breaking (0.x minor): `scripts/run-merge-mutation-reports.mjs` is gone.** Merge shard reports with `npx repo-contract merge-mutation --total <n> --out reports/mutation/mutation.json 1=<report> ...`. Merge to that path: an adopted report is judged where it lies, and no longer copied there. data-cap's `ci.yml` must switch.
- **New reusable workflow `.github/workflows/contract.yml`.** A `plan` job sizes the matrix with `repo-contract mutation plan --json`. Each shard runs Mutation with `IPC_MUTATION_SHARD`, and the contract job judges the merged report with `IPC_MUTATION_REPORT`. Call it pinned by SHA and keep a bare `contract` job, because GitHub names a called job `<caller> / contract`. `contract-args` may not hold `--scope` while `mutation-shards` is true. The `plan` job finds a package's own Stryker config under the same nine names as the Mutation check. This repository's own CI now runs through it, sharded.
- **An existing `contract.yml` is not replaced.** `init` leaves it as it is, so one written before this release keeps its own arguments, such as `--scope auto`. To move to the sharded caller, delete `.github/workflows/contract.yml` and run `init` again.
- **Breaking (0.x minor): `QuickStart` is a standard check.** A package that is not private now fails the contract until its README has a `<!-- quick-start:begin -->` block. To migrate, mark the README's install command and first run as that block. It costs a pack and an install of the tarball on every contract run; with `PackedConsumer`'s, that is two installs per run. In full local contract runs on 2026-11-16, it took 20.8 s for env-cap 0.8.0 and 29.5 s for data-cap 0.10.2. Those are each run's `QuickStart finished in` lines, with the other checks running alongside. `PackedConsumer` took 32.3 s and 44.7 s in the same runs. It is repo-contract's tier check, so a `private: true` package passes it as not applicable. A `"checks"` entry naming `QuickStart` is ignored, with one line on stderr saying so. `add check QuickStart` writes nothing and says why.
- **`verify-consumers --compare [--checks a,b]`.** It prints each check's verdict with the installed standard and with this one. It fails on any change, better or worse, that `ALLOWED_DIFFERENCES` does not explain. A `--skip` that leaves out every check `--checks` names exits 1 instead of comparing nothing. The second copy uses the standard's own copy of every package the consumer does not declare.
